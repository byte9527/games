# Games

一个无广告、无账号、无用户追踪，并可离线使用的小游戏合集。

在线地址：<https://byte9527.github.io/games/>

## 当前游戏

### 五子棋

- 15×15 棋盘，本地双人同屏对战
- 黑棋先手，双方均无禁手
- 横、竖或任一斜线连续五颗或更多同色棋子即获胜
- 棋盘下满且无人获胜时判定和棋
- 支持当前回合提示、获胜连线高亮、悔棋和重新开始
- 自动恢复当前浏览器中尚未结束的活动棋局
- 五子棋对局内置低音量中国风背景音乐，支持全局开关、偏好记忆和后台暂停
- 音乐由 Web Audio API 本地合成，不请求第三方音频资源，离线时仍可使用

当前版本是休闲规则五子棋，不包含人机对战、在线对战、账号或跨设备同步。

## 本地开发

需要 Node.js >=22.9.0 <23 和 npm 10.8.3。

```bash
npm ci
npm run dev
```

## 验证

首次运行端到端测试前，需要安装 Playwright（浏览器自动化测试工具）所需的浏览器：

```bash
npx playwright install chromium webkit
npm test
npm run typecheck
npm run build
npm run test:e2e
```

自动化端到端测试包含桌面和手机尺寸的 Chromium，以及手机尺寸的 Playwright WebKit 项目。不同浏览器对安装入口和 PWA（渐进式 Web 应用）能力的支持存在差异，实际安装方式以页面指引和浏览器菜单为准。

## PWA 与离线使用

首次联网成功打开后，应用会通过 Service Worker（后台缓存脚本）缓存运行所需的本地资源。之后可以从浏览器或已安装的桌面图标断网重新打开并游玩，包括使用由 Web Audio API 本地合成的五子棋背景音乐。页面会在浏览器支持直接安装时显示安装按钮，否则提供手动安装指引。

## 隐私

项目不包含广告、统计脚本或用户追踪，不会把棋局上传到服务端，也不会请求第三方音频资源。活动棋局和音乐开关偏好只保存在当前浏览器的 `localStorage` 中；终局不会作为历史记录保留，浏览器也可能按自身存储策略清理本地数据。

## 技术栈

项目使用 React、TypeScript、Vite、Vitest、Playwright 和 `vite-plugin-pwa` 构建。
